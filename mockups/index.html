Phase 1 • design only

SMM Panel — design mockups

Static HTML only: no PHP, no database, dummy data. Five front-site directions, a matching order & payment page for each, and two admin panel directions. Everything works in the browser — platform switching, live pricing, modals, filters and the import screen. Pick one front direction and one admin direction (mixing parts is fine).

1 Front site — 5 directions

All five share the same content and dummy data, so you are only choosing the look and the flow.

Direction A

Soft purple gradients, rounded cards, friendly and familiar. Closest to the viralborn.com feel. Service cards side by side with the quantity box inside each card.

Guided wizard — easiest

One question per screen with a progress bar: platform → service → quality → quantity → link → confirm. Big buttons, a quantity slider, and a review step before payment. Hardest to get wrong for a first-time buyer.

App style — mobile first

Feels like a phone app: a grid of platform tiles, a segmented service switcher, and a sticky bottom bar that always shows the running total. The whole page re-colours to the chosen platform, and the order form slides up as a bottom sheet.

What each admin panel contains
  • Dashboard — stat cards, provider balances with a Check balance button, recent orders
  • Orders — search plus status, platform and date filters, paging
  • Order detail — full order and payment data, provider order ID, profit, activity log, and every action (mark paid, send to provider, sync, refill, cancel, complete, refund)
  • Services — filters and bulk actions (activate, deactivate, set markup, sync prices, delete)
  • Import Services — provider picker, search and category filter, checkbox table, auto-detect toggle for platform and category, markup %, and update-vs-skip for services you already have
  • Settings — site details, theme colour, logo and favicon, contact, head code, order automation and the cron key
Notes on this phase

Platform icons are drawn as plain inline SVG glyphs rather than real brand logos, so nothing trademarked ships with the site. Prices are dummy and use ₹; the rate per 1,000 and the quantity presets come from one shared data table at the bottom of each file, which is also where the real services will plug in later. Checked at 375px and 1280px wide.
